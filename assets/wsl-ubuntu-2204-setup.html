WSL2 + Ubuntu 22.04 Setup

Windows Terminal first, then WSL bare, updated, then Ubuntu 22.04 on top.

01

Install Windows Terminal

Do the rest of this from Windows Terminal, not the default console host — proper copy/paste, tabs, and correct rendering of colored output make every step below easier. Install it from an admin PowerShell:

powershell — admin
winget install Microsoft.WindowsTerminal
Already have it, or on a build where winget isn't available? Grab it from the Microsoft Store and skip ahead.
02

Install WSL — no distro yet

Open a new tab in Windows Terminal running PowerShell as Administrator. This installs the WSL core and Virtual Machine Platform without pulling any Linux distro.

powershell — admin
wsl --install --no-distribution
Restart Windows once this finishes — the Virtual Machine Platform feature needs a reboot to take effect.
03

Update WSL

After the reboot, pull the latest WSL core before installing any distro on top of it.

powershell — admin
wsl --update
04

Install Ubuntu 22.04

Now add the distro itself.

powershell
wsl --install -d Ubuntu-22.04
05

Create your Linux user

Launch Ubuntu 22.04 from the Start menu, or its own tab in Windows Terminal. First run asks for a username and password — this is a Linux account, separate from Windows.

ubuntu-22.04 — first launch
Enter new UNIX username: trops
New password:
Retype new password:
Nothing appears on screen while you type the password — that's normal. Type it and press Enter, then type it again to confirm and press Enter once more.
06

Update packages

bash
sudo apt update && sudo apt upgrade -y
